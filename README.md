# WEB PORTOFOLIO ARKHOIRONI

Fitur Admin:

- **Projects** — kelola daftar proyek (judul, deskripsi, tech stack, gambar, link demo/GitHub), otomatis tampil di section "Projects" website.
- **Education** — kelola riwayat pendidikan.
- **Pengalaman / Organisasi** — kelola pengalaman kerja/organisasi.
- **Dashboard Admin** dengan login, ringkasan statistik, dan CRUD (Create, Read, Update, Delete) penuh untuk ketiga data di atas.

## Akses website & admin

- Website publik: `https://webdev.iam-publishing.com/`
- Akses admin : `https://webdev.iam-publishing.com/admin/login.php`

## Catatan

- Toggle bahasa (EN/ID) di halaman publik hanya menerjemahkan teks statis (About, Skills, dll). Konten dari database (Projects, Education, Pengalaman) ditampilkan apa adanya sesuai yang diinput admin — belum ada sistem multi-bahasa untuk data dinamis ini.
